# Lunar Landing Game

A small, playful little game where you try to land a spacecraft on the Moon without crashing. This project is a vibe-coded experiment to see how far a simple concept can go with a clean, fun gameplay loop.

## What is this?

This is a lightweight lunar landing game inspired by classic arcade-style landers. The goal is simple: descend carefully, manage your fuel, and touch down smoothly on the lunar surface.

It is intentionally minimal and designed as a fun side project to prototype gameplay, controls, and momentum-based physics without overengineering it.

## Features

- Simple lunar landing gameplay
- Basic thrust and gravity mechanics
- Survival objective: land safely without crashing
- Quick play loop
- Easy to tweak and expand
- Great as a small coding experiment or prototype

## Controls

Use the keyboard to fly the lander:

- W / Up Arrow: thrust upward
- A / D or Left / Right: rotate/steer
- Space: maybe used for a boost or action if you add one

If you want to tweak the controls, the logic is easy to adjust in the game code.

## How to run

Because this is a small project, you can usually run it in a browser by opening the main game file directly or serving the folder locally.

Example:

```bash
python -m http.server 8000
```

Then open:

```text
http://localhost:8000
```
